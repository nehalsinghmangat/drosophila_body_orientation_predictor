# drosophila_body_orientation_predictor

Repo for [Mangat et al. (2026)](https://www.biorxiv.org/content/10.64898/2026.03.30.715335v1.full). Predicts *Drosophila* body heading angle from flight trajectory data using a neural network trained on data from [van Breugel et al. (2014)](https://www.sciencedirect.com/science/article/pii/S0960982213015820).

## Installation

### 1. Clone the repo

```bash
git clone https://github.com/nehalsinghmangat/drosophila_body_orientation_predictor.git
cd drosophila_body_orientation_predictor
```

### 2. Download the experimental data

Raw data is archived on [Dryad](https://datadryad.org) in Parquet format. Download and place the files so the directory tree matches:

```
experimentaldata/
├── 30cms/
│   ├── flight_trajectories_3d_HCS_odor_horizon_matched.parquet
│   ├── body_orientations_HCS_odor_horizon_matched.parquet
│   └── body_trajec_matches.parquet
├── 40cms/
│   └── ...
└── 60cms/
    └── ...
```

### 3. Create and activate a virtual environment

Requires **Python 3.12**.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Download the external evaluation data

Orco-->CsChrimson laminar-wind trajectories used for heading-prediction evaluation are archived separately on [Dryad](https://datadryad.org/dataset/doi:10.5061/dryad.zw3r228fw). Download `orco_laminar1.csv`, `orco_traj2.csv`, and `orco_traj3.csv` from `trajectories_for_figures/` and place them in `experimentaldata/external/`:

```
experimentaldata/external/
├── orco_laminar1.csv
├── orco_traj2.csv
└── orco_traj3.csv
```

### 6. Launch JupyterLab (or Jupyter Notebook)

```bash
jupyter lab
```

## Workflow

Run **`notebooks/data_correction_and_model_training.ipynb`**. It combines data correction and model training into a single narrative:

1. **Data correction and processing.** Merges raw Parquet data across the three wind speeds, computes kinematic features (groundspeed, airspeed, thrust), and resolves the 180° heading ambiguity with `utils.naive_heading_correction_v2` — a single-step, thrust-magnitude-weighted heuristic with automatic spike detection and interpolation. Trajectories with a residual heading jump are filtered out, and every corrected trajectory can optionally be re-plotted for manual review (`pipelinedata/03_corrected/heading_correction_steps_svg/`).
2. **Motivating an ANN.** Fits 14 ordinary-least-squares/circular-regression baselines (thrust, airspeed, groundspeed, and every combination, in both linear and circular form) and shows that none of them is accurate across all flight-direction regimes — motivating a neural network.
3. **Selecting the architecture and loss function.** Searches over network depth/width (1–3 hidden layers, 10–30 neurons) and loss function (mean-squared error vs. a custom angular-distance loss, `utils.geodesic_loss`, with and without per-trajectory length weighting via `utils.trajectory_length_sample_weights`) using grouped 3-fold cross-validation (`GroupKFold`, keyed on trajectory identity, training trajectories only). The selected configuration — 3 hidden layers × 30 neurons, angular-distance loss, length-weighted samples — is trained on a trajectory-grouped 67/33 train/test split with wind-rotation augmentation applied only to the training trajectories.
4. **Evaluation.** Reports trajectory-level error (median error per trajectory, summarized with bootstrap confidence intervals) overall, by flight-direction regime, against all 14 baselines (Figure 1 Panel C), across 5 independently-seeded training runs, under leave-one-wind-speed-out generalization testing (train on 2 of 3 wind speeds, test on the third), and stratified against 7 kinematic covariates (airspeed, groundspeed, thrust magnitude, turning rate, slip angle, wind speed, and flight orientation).
5. **Prediction confidence.** Reuses the 5 seeded models as an ensemble to produce a ground-truth-free confidence signal (inter-model agreement), and provides `utils.check_inputs_in_training_range` to warn when new inputs fall outside the training data's range.
6. **External validation.** Applies the trained model to the David et al. external dataset as a qualitative generalization check.

Canonical outputs: `models/ann_wind_augmented_no_thrust_no_delay.keras`, `models/ensemble/`, `models/ann_lowo_heldout_*.keras`, and the analysis tables/figures under `pipelinedata/05_final/` and `figures/`.
