# drosophila_body_orientation_predictor

Repo for [Mangat et al. (2026)](https://www.biorxiv.org/content/10.64898/2026.03.30.715335v1.full). Predicts *Drosophila* body heading angle from flight trajectory data using a neural network trained on data from [van Breugel et al. (2014)](https://www.sciencedirect.com/science/article/pii/S0960982213015820).

## Installation

### 1. Clone the repo

```bash
git clone https://github.com/nehalsinghmangat/drosophila_body_orientation_predictor.git
cd drosophila_body_orientation_predictor
```

### 2. Download the experimental data

Raw data is archived on [Dryad](https://datadryad.org) in Parquet format. Download and place the files so the directory tree matches:

```
experimentaldata/
├── 30cms/
│   ├── flight_trajectories_3d_HCS_odor_horizon_matched.parquet
│   ├── body_orientations_HCS_odor_horizon_matched.parquet
│   └── body_trajec_matches.parquet
├── 40cms/
│   └── ...
└── 60cms/
    └── ...
```

### 3. Create and activate a virtual environment

Requires **Python 3.12**.

```bash
python3.12 -m venv .venv
source .venv/bin/activate
```

### 4. Install dependencies

```bash
pip install -r requirements.txt
```

### 5. Launch JupyterLab (or Jupyter Notebook)

```bash
jupyter lab
```

## Workflow

Run the notebooks in this order. **`notebooks/01_data_correction_and_processing.ipynb`** turns the raw data into the training-ready dataset (`trainingdata/04_trainingdata/`); **`notebooks/02_training_and_testing_the_ann.ipynb`** then trains and evaluates the model, **`notebooks/03_ann_vs_linear_models.ipynb`** compares it with the baselines, and **`notebooks/04_generate_tables.ipynb`** writes the paper tables (run in that order).

1. **Data correction and processing** (`01_data_correction_and_processing.ipynb`). Merges raw Parquet data across the three wind speeds, computes kinematic features (groundspeed, airspeed, thrust), and resolves the 180° heading ambiguity with `utils.naive_heading_correction_v2` — a single-step, thrust-magnitude-weighted heuristic with automatic spike detection and interpolation. Trajectories with a residual heading jump are filtered out, and every corrected trajectory can optionally be re-plotted for manual review (`trainingdata/03_corrected/heading_correction_steps_svg/`).
2. **ANN vs. linear models.** Fits 14 ordinary-least-squares/circular-regression baselines (thrust, airspeed, groundspeed, and every combination, in both linear and circular form) and compares their accuracy with the ANN overall and within each flight-direction regime.
3. **Selecting the architecture.** Searches over network depth/width (1–3 hidden layers, 10–30 neurons) with the custom angular-distance loss (`utils.geodesic_loss`) and per-trajectory length weighting (`utils.trajectory_length_sample_weights`), using grouped 3-fold cross-validation (`GroupKFold`, keyed on trajectory identity, training trajectories only). The selected configuration is trained on a trajectory-grouped 67/33 train/test split with wind-rotation augmentation applied only to the training trajectories.
4. **Evaluation.** Reports trajectory-level error (median error per trajectory, summarized with bootstrap confidence intervals) overall, by flight-direction regime, against all 14 baselines (Figure 1 Panel C), across 5 independently-seeded training runs, under leave-one-wind-speed-out generalization testing (train on 2 of 3 wind speeds, test on the third), and stratified against 7 kinematic covariates (airspeed, groundspeed, thrust magnitude, turning rate, slip angle, wind speed, and flight orientation).
5. **Prediction confidence.** Reuses the 5 seeded models as an ensemble to produce a ground-truth-free confidence signal (inter-model agreement), and provides `utils.check_inputs_in_training_range` to warn when new inputs fall outside the training data's range.

Canonical outputs: `models/ann_wind_augmented_no_thrust_no_delay.keras`, `models/ensemble/`, `models/ann_lowo_heldout_*.keras`, and the result CSVs and paper tables under `tables/`, and the figures under `figures/`.
